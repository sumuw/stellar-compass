## 观察

- **连续第六次零换血 + 零换位**：11-20、11-23、11-24、11-25、11-26、11-27 六期 16 席名单与名次逐位完全一致。榜单连续六期没有发现新项目，当前唯一有效信息只剩存量项目的增量节奏；这在 GitHub Trending 每日榜上相当罕见。
- **整体缩量但跌幅收窄**：全天增量从 10,612 降至 9,849（-7.2%），小于上一期的 -14.4%。16 席中仅 superpowers（+7%）、stitch-skills（+1%）、opensre（+0%）、Claude-BugHunter（+1%）未回落；firecrawl（-20%）与 diagram-design（-23%）跌幅最大，前几期的放量明星同步降温。
- **增量与排序持续脱钩**：增量前三是 Claude-BugHunter（+1,615，排第 1）、superpowers（+916，排第 2）、Ghost-Downloader-3（+843，排第 15）；另一头 nginx（+148，排第 7）与 OpenVINO（+152，排第 8）几乎垫底却卡在中上游。榜首与垫底日增相差约 10.9 倍。
- **技能包生态仍占主导**：7 席合计 +5,436，占全天约 55%，覆盖漏洞挖掘、开发方法论、Agent-Native CLI、图表设计规范、话题研究、UI 生成与合规审查，比例较上期的 54% 微升。app-store-compliance 的 125 种拒绝模式与 117 项法规截止日本期未变，纯惯性传播。
- **中文项目稳定四席**：minimind、AFFiNE、Ghost-Downloader-3、autoclip 合计 +2,712，占全天增量约 28%；Ghost-Downloader-3 以 +843 升至增量第三，autoclip 虽有回落但仍在增量前五。
- **时效信号**：13 席在 11-27 有新推送；CLI-Anything 停在 11-20（约 7 天）、stitch-skills 停在 11-24，是本期仅有的两条明显停更提示。superpowers 自 11-24 恢复推送后已连续三日更新，增量回升与其新提交同步。
