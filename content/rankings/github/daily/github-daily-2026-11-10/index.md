## 观察

1. **技能包赛道三席回潮**：anthropics/skills（官方）、addyosmani/agent-skills（Chrome 团队）、mattpocock/skills（个人头部）同榜，加上技能包相邻的 claude-quickstarts，Anthropic 生态周边占据 12 席中的 4 席。赛道从单日爆发转入「官方 + 头部作者」的结构性热度。
2. **留存率持续高位**：7/11 留存，连续三期留存过半，低位榜单 + 高留存的组合说明当前热度集中在少数持续发酵的项目上，而非轮动快闪。
3. **增量与排序脱钩成为常态**：增量前三 astryx（+3,111）、sherlock（+2,387）、anthropics/skills（+1,676）分列 1/9/2 位；增量仅 +192 的 topcoat 排第 10，GitHub Trending 排序权重对星增速之外的因素（如绝对热度、fork、讨论）赋予的权重仍然显著。
4. **Rust 生态双线开花**：tokio 官方新框架 topcoat（基建线新面孔）与 agent-browser（应用线常青）同榜，Rust 在 Web 基建与 Agent 工具两个方向同时占据心智。
5. **⚠️ 时效标注**：addyosmani/agent-skills 停更约 9 天（最后推送 11-01），属存量惯性传播；anthropics 双仓库最后推送 11-06（4 天），其余 9 席今日均有推送。
