## 观察

1. **零换血日**：16 席与名次逐位一致（Claude-BugHunter → autoclip），仅增量变化；这在近两个月的榜单中属首次，通常意味着趋势热度由新项目扩散转为存量项目深耕。
2. **技能包从「数量」转向「垂类纵深」**：安全（Claude-BugHunter）、方法论（superpowers）、研究（last30days-skill）、UI（stitch-skills）、合规（app-store-compliance）、设计规范（diagram-design）六席同日，且合规/设计两席作为昨日新面孔继续放量（+874 / +634）。
3. **中文工具扎堆且增速最快**：Ghost-Downloader-3（+1,082，增量第三）、autoclip（+983，增量第四）、minimind（+841，较昨日近 3 倍）、AFFiNE（+686，较昨日约 4 倍）四席合计 +3,592，占全天增量约 30%。
4. **脱钩与低基数爆发**：榜首 Claude-BugHunter +1,660 同时是增量王；第 15/16 名的 Ghost-Downloader-3 与 autoclip 分列增量第三/第四，而第 8 名 openvino 仅 +219 垫底。opensre +25 → +465（约 18 倍）、app-store-compliance 总星 2,649 却 +874，均属低基数放大，需警惕次日回落。
5. **时效与惯性**：superpowers 停更 17 天仍以 +888 排第 2；nginx、minimind、diagram-design、app-store-compliance 最后推送在 11-18 / 11-19，热度主要来自传播惯性而非当日提交。
