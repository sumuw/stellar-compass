# 每日全球高分影视雷达

## 概述

实时检索全球近期影视内容，发现真正值得看的高质量作品。**不凭模型记忆推荐，不搬运 IMDb/豆瓣/烂番茄榜单。** 每次执行都是全球候选发现 → 身份归一化 → 去重 → 跨平台评分 → 结构化推荐的完整流程。

核心排序固定：**质量 > 真实口碑 > 跨平台共识 > 样本可信度 > 时效性 > 热度**

## 核心原则

1. **实时检索**：必须通过 WebSearch/WebFetch 实时检索，不凭模型记忆推荐
2. **宁缺毋滥**：达标不足时少推荐，0 部时直接写"今天没有发现达到正式推荐标准的新作品"
3. **数据诚实**：无法可靠确认的数据写"暂无可靠数据"，不猜测不伪造
4. **长期维护**：每次执行当作长期影视数据库维护，而非一次性回答

## 检索范围

### 地区覆盖

全球所有国家和地区，主动覆盖：

| 区域 | 主要市场 |
|------|----------|
| 东亚 | 中国大陆/港澳台、日本、韩国 |
| 北美 | 美国、加拿大 |
| 欧洲 | 英国、法国、德国、西班牙、意大利、北欧、东欧 |
| 南亚/东南亚 | 印度、东南亚 |
| 大洋洲 | 澳新 |
| 拉美 | 拉美各国 |
| 中东/非洲 | 中东、非洲 |

**不因知名度低而忽略非英语高口碑作品。**

### 内容类型

**包含：**
- 电影
- 电视剧
- 限定剧 / Mini Series
- 网络剧
- 流媒体原创
- 动画电影
- 动画 / Anime
- 纪录片 / 纪录剧集
- 高质量综艺 / 真人秀
- 特别篇
- 其他具有独立观看价值的正式影视作品

**排除：** 普通短视频、自媒体、普通 YouTube 节目、直播、普通网络栏目、纯资讯节目

## 时间窗口

| 优先级 | 时间范围 | 说明 |
|--------|----------|------|
| 优先 | 最近 90 天 | 首播/上映/上线/完结 |
| 其次 | 最近半年 | 仍高热或持续形成口碑 |
| 可关注 | 更早 | 因新上流媒体、新一季、重大影视奖项、国际口碑发酵或大结局造成显著口碑变化而重新成为热点 |

**默认不推荐失去近期讨论价值的经典老作品。**

## 质量判断方法论

### 跨平台数据源

按内容类型选择合适平台：

| 类别 | 中文社区 | 国际社区 | 专业评价 |
|------|----------|----------|----------|
| 通用 | 豆瓣 | IMDb、TMDb、Trakt | Rotten Tomatoes、Metacritic |
| 电影 | 豆瓣 | IMDb、Letterboxd、TMDb | RT、Metacritic、电影节/奖项 |
| 亚洲剧集 | 豆瓣 | MyDramaList、TMDb | — |
| 动画/Anime | 豆瓣 | MyAnimeList、AniList | — |
| 本土作品 | 当地代表性社区 | 对应国际社区 | 当地主流媒体 |

**专业评价只能作为辅助，不能替代真实观众口碑。**

### 优先信号

- 中外用户评价高 + 专业评价较好 + 样本充足 + 当前有热度 + 趋势稳定
- 本土与国际社区同时认可
- 完结后仍稳、开分后不跳水
- 小众作品正形成国际口碑

### 警惕信号

- 小样本虚高
- 粉丝集中评分
- 刷分
- 两极化

**不同平台评分禁止简单算术平均。**

### 必须核实的数据

每次必须核实（无法确认则写"暂无可靠数据"）：
- 当前评分
- 评价样本量
- 上映/播出/完结状态
- 流媒体上线状态和可观看性

## 评分系统

### 综合推荐指数（0-100）

内部排序指标，综合考虑：
- 国内真实用户评价
- 海外真实用户评价
- 专业评价
- 样本量
- 跨平台一致性
- 评分稳定性
- 当前热度
- 合法可观看性

### 推荐等级

| 指数 | 等级 | 含义 |
|------|------|------|
| 95-100 | 🏆 | 年度级 / 极强推荐 |
| 90-94 | 🔥 | 强烈推荐 |
| 85-89 | ⭐ | 推荐 |
| 80-84 | 🧪 | 值得关注（潜力高分 · 样本量暂不足，优先进入观察池） |

**原则上低于 80 不进正式推荐。**

## 状态管理与去重

### 五种状态

| 标记 | 状态 | 说明 |
|------|------|------|
| 🆕 | NEW | 新推荐 |
| ⭐ | WATCHLIST | 想看 |
| ✅ | WATCHED | 已看 |
| 🚫 | EXCLUDED | 不感兴趣 |
| 👀 | HOLD | 暂缓观察 |

### 状态优先级

**🚫 > ✅ > ⭐ > 👀 > 🆕**

用户输入映射：
- "想看/加入想看/收藏/以后提醒我看" → WATCHLIST
- "已看/看过了/这个我看了" → WATCHED
- "不感兴趣/不想看/别再推荐/排除/不喜欢这个" → EXCLUDED
- "暂缓/继续观察" → HOLD

### 去重流程

```
全球候选
  → 身份归一化（大陆/港/台译名、英文名、原名、简繁体、标点差异、别名）
  → 排除已看 (✅)
  → 排除不感兴趣 (🚫)
  → 排除历史已正式推荐
  → 排除想看重复 (⭐)
  → 检查观察池 (👀)
  → 高分筛选
  → 今日真正新推荐 (🆕)
```

**能确认 IMDb ID、TMDb ID、豆瓣 ID 等稳定唯一 ID 时优先用唯一身份判断。**

### HOLD 升级规则

HOLD 状态在满足稳定高口碑条件后可**第一次**升级为正式推荐。

### 历史作品动态

已推荐作品只有在**重要变化**时进入"📈 历史作品动态"：
- 正式完结
- 结局导致显著口碑变化
- 综合判断明显涨跌
- 从小众变全球爆款
- 正式上线重要流媒体
- 获得重要国际奖项
- 大规模口碑反转

**必须标记"历史已推荐，本次仅为状态更新"，不计入今日新增。**

### 历史可靠性要求

- 不要假装拥有无法读取的持久数据
- 如当前执行无法完整访问此前推荐状态，必须写：**⚠️ 当前无法完整访问历史推荐状态，本次去重可能不完整。**
- 禁止声称已完成全历史严格去重

## 执行流程

### 第一步：全球候选发现

使用 WebSearch 按区域和内容类型搜索近期高分作品。搜索策略：
- 按地区搜索："最近高分 [国家] 电影/电视剧"
- 按平台搜索：Netflix/Disney+/Max/Prime Video/Apple TV+ 等近期上线高口碑作品
- 按类型搜索：anime/纪录片/限定剧等
- 按社区搜索：豆瓣/IMDb/Letterboxd 近期高分
- 按奖项搜索：最近电影节/颁奖季获奖作品

### 第二步：身份归一化与去重

对每个候选进行身份归一化，然后按去重流程排除。

### 第三步：跨平台评分核实

对通过去重的候选，逐一用 WebSearch/WebFetch 核实各平台评分和样本量。

### 第四步：综合评分与分级

根据跨平台数据给出综合推荐指数和等级。

### 第五步：生成报告

按 `template-report.md` 模板组装最终报告。

### 第六步：发布到 Stellar Compass（完整闭环：生成 → 提交 → 推送 → 上线）

报告生成后，将其发布到 Stellar Compass 站点并推送上线。

#### 6.1 生成 Hugo leaf bundle

如果当前项目是 Stellar Compass（含 `content/rankings/` 目录），在项目根目录下创建：

```
content/rankings/film-radar/daily/film-radar-daily-<date>/
  index.md       # front matter + 报告正文
  ranking.json   # 结构化数据
```

`index.md` front matter 格式：

```yaml
---
title: 今日全球高分影视雷达 <date>
description: <一句话总结>
date: '<date>T08:00:00+08:00'
rankingKey: '<date>'
slug: film-radar-daily-<date>
categories:
  - film-radar
periods:
  - daily
tags:
  - 影视
  - 推荐
  - 评分
draft: false
---
```

`ranking.json` 格式：

```json
{
  "category": "film-radar",
  "period": "daily",
  "date": "<date>",
  "source": "film-radar",
  "sourceUrl": "https://www.workbuddy.cn",
  "items": [
    {
      "rank": 1,
      "name": "中文名（英文名）",
      "url": "流媒体链接",
      "description": "评分摘要",
      "type": "电影/电视剧/动画/纪录片",
      "platform": "平台名",
      "score": "92/100 🔥",
      "tags": ["标签1", "标签2"],
      "comment": "简评"
    }
  ]
}
```

#### 6.2 更新状态追踪文件

更新 `skills/film-radar/status-tracker.json`：追加本次新推荐作品、更新统计数字和 `$updatedAt`。

#### 6.3 运行发布脚本（自动完成验证 → 构建 → 提交 → 推送）

```bash
cd <Stellar Compass 项目根目录>
node scripts/publish-daily.mjs --category film-radar
```

发布脚本自动执行完整管道：

| 步骤 | 内容 | 失败行为 |
|------|------|----------|
| 1 | 定位当日 bundle | 缺失则中止，提示先生成 |
| 2 | 内容验证（validate-content.mjs） | 中止，不提交 |
| 3 | 单元测试 | 中止，不提交 |
| 4 | Hugo 构建（含权限问题自动清理重试） | 中止，不提交 |
| 5 | 站点输出测试 | 中止，不提交 |
| 6 | git add/commit + push origin main | push 失败降级（见下） |

常用参数：`--date YYYY-MM-DD`（默认今天）、`--dry-run`（只跑门禁不发布）、`--skip-push`（提交不推送）、`--message "..."`（自定义提交信息）。

脚本已内置处理 **PortableGit loose ref rename bug**（commit 后 `refs/heads/main` 丢失的问题会自动修复，无需人工干预）。

#### 6.4 推送降级（无凭据环境）

当前自动化环境无 GitHub 凭据时，脚本完成本地提交后输出手动推送命令：

```bash
cd <项目根目录> && git push origin main
```

此时应在报告末尾注明：**"站点待手动推送后更新"**，并附上站点地址。

#### 6.5 报告部署状态

- push 成功：报告 GitHub Actions 构建地址和站点地址（`https://sumuw.github.io/stellar-compass/rankings/film-radar-daily-<date>/`，约 2-3 分钟后生效）
- push 降级：注明待手动推送，附手动命令

### 第七步（备选）：0 部推荐时

当日无达标作品时**仍需运行发布脚本**（提交 status-tracker 更新），但站点不会产生新 bundle。报告正文直接写"今天没有发现达到正式推荐标准的新作品。"

## 每日目标

- 正式推荐：3-8 部，最多 10 部
- 达标不足时少推荐
- 0 部时写"今天没有发现达到正式推荐标准的新作品"
- 可提供少量观察池更新，但不得冒充正式推荐

## 电影特殊规则

- 正式推荐优先已上线流媒体/数字发行/PVOD
- 核实平台：Netflix、Disney+、Max、Prime Video、Apple TV+、Hulu、Paramount+、Peacock、MUBI、Criterion Channel、腾讯视频、爱奇艺、优酷、哔哩哔哩等
- 注明地区限制，**禁止把某地区可看写成全球可看**
- 仍主要院线且未数字发行的电影原则上不进主推荐
- 极高口碑者可放"🎞️ 影院高分观察"，每天最多 1-2 部，不计入正式新增

## 电视剧特殊规则

- 必须按"季"评价，当前季视为独立推荐对象
- 核实：当前季评分、评价人数、单集趋势、播出进度、是否完结、大结局评价
- 判断口碑走向：高开低走 / 低开高走 / 烂尾 / 口碑反转
- **同一季只能正式推荐一次**

## 输出格式

详见 `template-report.md`。

核心结构：
1. 标题 + 日期
2. 一句话总结
3. 🏆 今日新推荐（按指数降序，每部含完整信息卡）
4. 👑 如果今天只看一部
5. 💎 今日隐藏宝藏（可选，最多 1-2 部）
6. 👀 高分观察池（可选，最多 3 部）
7. 🎞️ 影院高分观察（可选，最多 1-2 部）
8. 📈 历史作品动态（可选，只报实质变化）
9. 影视库状态

### 每部推荐包含

1. 中文名 / Original Title
2. 作品编号：FXXX（历史中保持唯一连续）
3. 综合推荐指数：XX/100
4. 推荐等级：🏆/🔥/⭐/🧪
5. 类型；国家/地区；年份；当前状态；首播/上线日期；播出进度；可观看平台；流媒体地区限制
6. 📊 真实口碑：各平台评分/评价人数（无数据则省略或"暂无可靠数据"）
7. 📈 口碑判断：跨平台一致性（高/中/低）、样本可信度（高/中/低）、口碑趋势（稳定/上升/下降/样本不足/两极化）
8. 为什么值得看：2-4 句话（不剧透）
9. 适合谁：一句话
10. 我的状态：🆕 新推荐

### 交互提示

报告末尾提示用户可回复：
- `F001 想看` / `F002 已看` / `F003 不感兴趣` / `F004 暂缓`
- 也接受直接按片名标记

## 写作风格

- 不写营销软文
- 不大段复述剧情
- 不剧透重大情节
- 不因热度、平台首页推广、奖项或冷门地区而降低标准
- 客观简洁，避免夸大或不实描述

## 注意事项

- 必须通过实时 WebSearch 检索，不凭模型记忆
- 样本不足但潜力很高的作品标 🧪，优先进入观察池而非最高级正式推荐
- 不为凑数量重推旧作
- 不假装拥有无法读取的持久数据
- 如当前界面不支持可靠持久化的交互控件，不要假装点击可永久写入数据库
